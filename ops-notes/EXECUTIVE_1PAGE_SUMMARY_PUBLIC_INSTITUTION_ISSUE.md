# 공공기관 접속 이슈 1페이지 요약 (경영진 보고용)

## 1. 이슈 개요
- 공공기관(예: 전력거래소, 남부발전) 접속 시 일부 페이지에서 데이터가 표시되지 않는 현상 발생.
- 사이트 자체 접속은 가능하나, 외부 데이터 호출 구간에서 실패 발생.

## 2. 핵심 원인 판단
- 현재 서비스 일부 기능이 Google Apps Script 직접 호출 구조임.
- 공공기관망 보안정책(외부 도메인 차단/프록시/SSL 검사/CORS 정책)과 충돌할 가능성이 높음.
- 결론: 코드 결함 가능성보다 접속 환경 제약 영향이 큼.

## 3. 비즈니스 영향
- 기관 고객의 서비스 신뢰도 저하
- 신청/문의 전환율 저하 가능성
- 운영팀 수기 대응(전화/이메일) 증가

## 4. 대응 전략
### 단기 (즉시)
- 기관 IT에 Google 스크립트 도메인 허용 요청 병행
- 사용자 안내 문구 및 대체 접수 채널(전화/이메일) 제공
- 실패 로그 수집 체계 강화

### 중기 (구조 개선)
- 브라우저의 Google 직접 호출을 서버리스 중계 API 구조로 전환
- 구조: 사용자 브라우저 -> 중간 API -> Apps Script -> Google Sheet
- 우선순위: 아카데미 신청/신청확인 기능부터 전환

### 장기 (운영 안정화)
- 조회형 페이지는 JSON 캐시/자동배포로 단계적 전환
- 공공기관 접속 안정성 및 장애 복원력 강화

## 5. 비용/환경 제약
- GitHub Pages(정적 호스팅) 환경에서도 구현 가능
- Cloudflare Workers 등 무료 플랜으로 시작 가능
- 트래픽 증가 시 유료 전환 검토 필요

## 6. 의사결정 요청 사항
1. 단기: 기관 IT 협조 요청 및 대체 접수 운영 승인
2. 중기: 신청/신청확인 기능 서버리스 전환 착수 승인
3. 장기: 조회형 데이터 구조 개선 로드맵 승인

## 7. 보고 결론
- 본 이슈는 공공기관망 정책 영향 가능성이 높으며, 단기 대응만으로는 재발 가능성이 존재함.
- 따라서 즉시 운영 보완 + 구조 개선을 병행하는 2트랙 대응이 필요함.
