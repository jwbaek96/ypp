# 워커 테스트 폴더

목적
- 운영 페이지를 수정하지 않고 Worker 중계 API를 안전하게 검증하기 위한 테스트 전용 폴더입니다.

파일
- index.html: courses/apply/check 3개 엔드포인트를 호출하는 단순 테스트 페이지

사용 방법
1. 브라우저로 index.html 파일을 엽니다.
2. Worker Base URL을 확인합니다.
3. 버튼을 눌러 API 응답을 확인합니다.

주의
- 이 폴더는 테스트 전용입니다.
- 운영 코드와 직접 연결하지 않습니다.
- apply 테스트는 실제 데이터가 저장될 수 있으니 필요 시 테스트용 값으로만 실행하세요.
