## 인수인계 요약 (전달용)
1. Cloudflare Worker 중계 API는 배포/동작 검증 완료 상태입니다.
2. 현재 운영 URL은 `https://ypp-api-relay.yppapi.workers.dev` 입니다.
3. 실행/요청 스펙은 `ypp-api-relay/README.md` 기준으로 따라오면 됩니다.
4. Worker 실제 라우팅/변환 로직은 `ypp-api-relay/src/index.ts`에 있습니다.
5. 업스트림 URL 및 CORS 등 배포 설정은 `ypp-api-relay/wrangler.jsonc`에 있습니다.
6. Apps Script 매핑은 아래와 같습니다.
	- courses -> `apps-script-files/code2.gs`
	- apply -> `apps-script-files/code3.gs`
	- check -> `apps-script-files/code1.gs`
7. check는 `name/phone`뿐 아니라 `email/companyName` 조건도 지원합니다.
8. 프론트 연동 시 courses 응답 구조는 `psac/relay` 2개 묶음이므로 단일 배열 가정 코드는 확인이 필요합니다.
